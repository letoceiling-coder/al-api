### Анализ недоступных фотографий

**Причина недоступности:** Timeout при проверке (cURL error 28: Connection timed out after 10 seconds)

**Наблюдения:**
- Все недоступные фотографии находятся в списках объектов (`list.image`)
- Фотографии из детальной информации объекта доступны на 100%
- Проблема может быть связана с:
  - Медленным ответом CDN при HEAD запросах
  - Временными проблемами сети
  - Ограничениями CDN на HEAD запросы

**Рекомендации:**
1. Увеличить timeout для проверки фотографий до 30 секунд
2. Использовать GET запрос вместо HEAD для более надежной проверки
3. Реализовать retry механизм для недоступных фотографий
4. Кэшировать результаты проверки доступности
