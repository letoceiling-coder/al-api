# Справка по моделям AI: Gemini и OpenAI

## Google Gemini API

### Доступные модели Gemini

#### 1. Gemini 1.5 Pro (gemini-1.5-pro)
- **Описание**: Самая мощная модель Gemini, поддерживает мультимодальность
- **Контекст**: До 1 миллиона токенов
- **Использование**: Сложные задачи, анализ документов, кодирование, мультимодальные задачи
- **Особенности**: 
  - Поддержка текста, изображений, видео, аудио
  - Функция вызова (function calling)
  - Streaming ответы
  - JSON режим

#### 2. Gemini 1.5 Flash (gemini-1.5-flash)
- **Описание**: Быстрая и эффективная модель
- **Контекст**: До 1 миллиона токенов
- **Использование**: Быстрые ответы, чат-боты, простые задачи
- **Особенности**:
  - Низкая задержка
  - Экономичная
  - Поддержка мультимодальности
  - Streaming

#### 3. Gemini 1.5 Pro Latest (gemini-1.5-pro-latest)
- **Описание**: Последняя версия Pro модели
- **Использование**: Всегда получаете последние обновления

#### 4. Gemini 1.0 Pro (gemini-pro)
- **Описание**: Стабильная версия Pro
- **Использование**: Продакшн приложения, где нужна стабильность

#### 5. Gemini 1.0 Pro Vision (gemini-pro-vision)
- **Описание**: Модель с поддержкой изображений
- **Использование**: Анализ изображений, OCR, описание картинок

### Примеры использования моделей Gemini

```php
// Gemini 1.5 Pro для сложных задач
$model = 'gemini-1.5-pro';

// Gemini 1.5 Flash для быстрых ответов
$model = 'gemini-1.5-flash';

// Gemini Pro Vision для работы с изображениями
$model = 'gemini-pro-vision';
```

### Функции Gemini API

1. **Генерация текста** - создание контента, ответы на вопросы
2. **Мультимодальный анализ** - работа с текстом, изображениями, видео
3. **Function Calling** - вызов внешних функций
4. **Streaming** - потоковая генерация ответов
5. **Embeddings** - создание векторных представлений
6. **Безопасность** - встроенная фильтрация контента

## OpenAI API

### Доступные модели OpenAI

#### GPT-4 серия

##### 1. GPT-4 Turbo (gpt-4-turbo-preview, gpt-4-0125-preview)
- **Описание**: Самая мощная модель OpenAI
- **Контекст**: 128K токенов
- **Использование**: Сложные задачи, анализ, программирование
- **Особенности**:
  - Высокое качество ответов
  - Поддержка JSON режима
  - Function calling
  - Vision (анализ изображений)

##### 2. GPT-4 (gpt-4)
- **Описание**: Стабильная версия GPT-4
- **Использование**: Продакшн приложения

##### 3. GPT-4 Vision (gpt-4-vision-preview)
- **Описание**: GPT-4 с поддержкой изображений
- **Использование**: Анализ изображений, описание картинок

#### GPT-3.5 серия

##### 4. GPT-3.5 Turbo (gpt-3.5-turbo)
- **Описание**: Быстрая и экономичная модель
- **Контекст**: 16K токенов (gpt-3.5-turbo-16k)
- **Использование**: Чат-боты, простые задачи, быстрые ответы
- **Особенности**:
  - Низкая стоимость
  - Высокая скорость
  - Function calling
  - JSON режим

##### 5. GPT-3.5 Turbo 16K (gpt-3.5-turbo-16k)
- **Описание**: GPT-3.5 с увеличенным контекстом
- **Контекст**: 16K токенов
- **Использование**: Длинные документы, расширенный контекст

#### Специализированные модели

##### 6. DALL-E 3 (dall-e-3)
- **Описание**: Генерация изображений
- **Использование**: Создание изображений по текстовому описанию
- **Размеры**: 1024x1024, 1792x1024, 1024x1792

##### 7. Whisper (whisper-1)
- **Описание**: Распознавание речи
- **Использование**: Транскрипция аудио, перевод речи
- **Форматы**: MP3, MP4, MPEG, MPGA, M4A, WAV, WEBM

##### 8. Text Embeddings (text-embedding-3-small, text-embedding-3-large, text-embedding-ada-002)
- **Описание**: Векторные представления текста
- **Использование**: Поиск, кластеризация, рекомендации
- **Размерность**: 1536 (small), 3072 (large), 1536 (ada-002)

##### 9. TTS (Text-to-Speech) модели
- **tts-1**: Стандартная модель синтеза речи
- **tts-1-hd**: Высококачественная модель синтеза речи
- **Голоса**: alloy, echo, fable, onyx, nova, shimmer

##### 10. Moderation (text-moderation-latest, text-moderation-stable)
- **Описание**: Модерация контента
- **Использование**: Проверка текста на токсичность, безопасность

### Примеры использования моделей OpenAI

```php
// GPT-4 Turbo для сложных задач
$model = 'gpt-4-turbo-preview';

// GPT-3.5 Turbo для быстрых ответов
$model = 'gpt-3.5-turbo';

// GPT-4 Vision для анализа изображений
$model = 'gpt-4-vision-preview';

// DALL-E для генерации изображений
$model = 'dall-e-3';

// Whisper для транскрипции
$model = 'whisper-1';
```

### Функции OpenAI API

1. **Chat Completions** - диалоговые модели (GPT-4, GPT-3.5)
2. **Completions** - текстовые модели (legacy)
3. **Images** - генерация изображений (DALL-E)
4. **Audio** - транскрипция и перевод (Whisper)
5. **Embeddings** - векторные представления
6. **Moderation** - модерация контента
7. **Fine-tuning** - дообучение моделей
8. **Function Calling** - вызов внешних функций
9. **Streaming** - потоковая генерация
10. **JSON Mode** - структурированные ответы

## Рекомендации по выбору модели

### Для Gemini:
- **Сложные задачи, анализ документов**: `gemini-1.5-pro`
- **Быстрые ответы, чат-боты**: `gemini-1.5-flash`
- **Работа с изображениями**: `gemini-pro-vision` или `gemini-1.5-pro`

### Для OpenAI:
- **Сложные задачи, программирование**: `gpt-4-turbo-preview`
- **Быстрые ответы, чат-боты**: `gpt-3.5-turbo`
- **Анализ изображений**: `gpt-4-vision-preview`
- **Генерация изображений**: `dall-e-3`
- **Транскрипция аудио**: `whisper-1`
- **Поиск и рекомендации**: `text-embedding-3-large`

## Пример конфигурации в Laravel

```php
// config/ai.php
return [
    'gemini' => [
        'api_key' => env('GEMINI_API_KEY'),
        'default_model' => 'gemini-1.5-pro',
        'models' => [
            'pro' => 'gemini-1.5-pro',
            'flash' => 'gemini-1.5-flash',
            'vision' => 'gemini-pro-vision',
        ],
    ],
    'openai' => [
        'api_key' => env('OPENAI_API_KEY'),
        'default_model' => 'gpt-4-turbo-preview',
        'models' => [
            'gpt4' => 'gpt-4-turbo-preview',
            'gpt35' => 'gpt-3.5-turbo',
            'vision' => 'gpt-4-vision-preview',
            'dalle' => 'dall-e-3',
            'whisper' => 'whisper-1',
        ],
    ],
];
```
