### ✅ 1. Добавлен новый метод в ParserController

**Метод:** `startFull()`

**Функционал:**
- ✅ Запускает полный парсинг всех типов объектов (`--type=all`)
- ✅ Автоматически запускает анализ данных после завершения парсинга
- ✅ Поддерживает Windows и Linux/Unix
- ✅ Создает скрипт для последовательного выполнения парсинга и анализа

**Параметры:**
- `region` - регион (по умолчанию: spb)
- `limit` - лимит объектов (по умолчанию: 100000)
- `details` - парсить детали (по умолчанию: true)
- `save_raw` - сохранять сырые данные (по умолчанию: true)
- `auto_analyze` - автоматически запустить анализ (по умолчанию: true)

**Маршрут:** `POST /api/trendagent/parser/start-full`

## 🔧 ТЕХНИЧЕСКИЕ ДЕТАЛИ

### Логика работы:

1. **При нажатии кнопки "Полный парсинг + Анализ":**
   - Показывается подтверждение
   - Отправляется POST запрос на `/api/trendagent/parser/start-full`
   - Создается скрипт (`.sh` для Linux, `.bat` для Windows)
   - Скрипт последовательно выполняет:
     1. Полный парсинг всех типов объектов
     2. Автоматический запуск анализа данных

2. **Скрипт сохраняется в:**
   - `storage/scripts/full_parse_with_analysis_{region}_{timestamp}.sh` (Linux)
   - `storage/scripts/full_parse_with_analysis_{region}_{timestamp}.bat` (Windows)

3. **Логи сохраняются в:**
   - `storage/logs/parser_full_{region}_{timestamp}.log`
