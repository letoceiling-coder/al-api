# Альтернативное Решение: Парсинг по Типам Комнат

## 🔍 Проблема с Фильтром Region

Тестирование показало, что параметр `region` **не работает** в API TrendAgent:
- С фильтром и без - одинаковые результаты
- API возвращает те же 344 объекта
- Районы в результатах не меняются

## 💡 Альтернативное Решение

### Для Домов

**Текущий код:**
```php
'room' => [30, 40]  // 30=Коттеджи, 40=Таунхаусы
```

**Разделяем на два запроса:**
```php
// Запрос 1: Только коттеджи
'room' => [30]  // до 344 объектов

// Запрос 2: Только таунхаусы
'room' => [40]  // до 344 объектов
```

**Результат:** До 688 объектов вместо 344

---

### Для Коммерции

**Текущий код:**
```php
'room' => [110, 120, 130]  // Офис, Торговое, Склад
```

**Разделяем:**
```php
// Запрос 1: Офисы
'room' => [110]  // до 344 объектов

// Запрос 2: Торговые помещения
'room' => [120]  // до 344 объектов

// Запрос 3: Склады
'room' => [130]  // до 344 объектов
```

**Результат:** До 1,032 объектов вместо 344

---

### Для Участков

У участков нет `room`, но есть другие параметры:
- `area_min` / `area_max` - площадь
- `price_min` / `price_max` - цена

**Стратегия: Разбить по ценовым диапазонам**

```php
$priceRanges = [
    ['price_min' => 0, 'price_max' => 5000000],
    ['price_min' => 5000000, 'price_max' => 10000000],
    ['price_min' => 10000000, 'price_max' => 20000000],
    ['price_min' => 20000000, 'price_max' => 999999999],
];
```

---

### Для Паркингов

Паркинги уже используют двухуровневую логику и дают лучший результат (416).

Можно улучшить, разбив комплексы по типам:
```php
// room=60 для паркингов
'room' => [60]
```

Или попробовать дополнительные фильтры на уровне комплексов.

## 🛠️ Реализация

### Шаг 1: Обновить ParseCommand

Добавить метод `parseByRoomTypes()`:

```php
private function parseByRoomTypes(string $type, array $roomTypes): array
{
    $totalProcessed = 0;
    $allIds = [];  // Для дедупликации
    
    foreach ($roomTypes as $roomType) {
        $this->info("Парсинг {$type} с room={$roomType}");
        
        $offset = 0;
        while ($offset < 344) {  // Лимит API
            $params = [
                'city' => $this->region,
                'room' => [$roomType],
                'count' => 100,
                'offset' => $offset,
            ];
            
            $data = $this->apiClient->{'get' . ucfirst($type)}($params);
            $items = $data['data'] ?? [];
            
            if (empty($items)) {
                break;
            }
            
            // Дедупликация по _id
            foreach ($items as $item) {
                $id = $item['_id'] ?? null;
                if ($id && !in_array($id, $allIds)) {
                    $allIds[] = $id;
                    // Сохранение...
                    $totalProcessed++;
                }
            }
            
            $offset += 100;
        }
    }
    
    return ['processed' => $totalProcessed, 'errors' => 0];
}
```

### Шаг 2: Обновить методы парсинга

```php
private function parseHouses(int $offset, $bar): array
{
    return $this->parseByRoomTypes('houses', [30, 40]);
}

private function parseCommercial(int $offset, $bar): array
{
    return $this->parseByRoomTypes('commercial', [110, 120, 130]);
}
```
