# Исправление проблемы с отображением фотографий

**Дата:** 2026-02-06  
**Проблема:** Фотографии не отображались корректно в React приложении

## Проблема

В React приложении фотографии не отображались из-за неправильной обработки URL изображений. API TrendAgent возвращает изображения в различных форматах:
- Готовые URL
- Объекты с полями `path` и `file_name`
- Массивы изображений
- Различные варианты полей (`url`, `url_full`, `src`, `image`, и т.д.)

## Решение

### 1. Создана утилита для обработки изображений

Создан файл `src/utils/imageUtils.js` с функциями:
- `getImageUrl(img)` - получает URL миниатюры изображения
- `getImageUrlFull(img)` - получает URL полного размера изображения
- `getImageUrls(img)` - получает объект с обоими URL

### 2. Обновлены все компоненты

Исправлена обработка изображений во всех компонентах:

**ObjectCard.jsx:**
- Добавлена поддержка массива `images`
- Добавлена поддержка формирования URL из `path` и `file_name`
- Формат: `https://selcdn.trendagent.ru/images/${path}/m_${fileName}`

**ObjectHeader.jsx:**
- Использует утилиту для обработки изображений из `renderer`
- Поддерживает различные форматы данных

**ObjectApartments.jsx:**
- Использует утилиту для планировок квартир

**ObjectAdvantages.jsx:**
- Использует утилиту для изображений преимуществ

**ObjectProgress.jsx:**
- Использует утилиту для фотографий хода строительства

**ObjectFinishing.jsx:**
- Использует утилиту для изображений отделки

**ObjectLocation.jsx:**
- Использует утилиту для изображений мест рядом

### 3. Логика обработки изображений

Утилита обрабатывает следующие варианты:

1. **Строка (URL или путь):**
   - Если начинается с `http://` или `https://` - возвращает как есть
   - Если начинается с `/` - добавляет базовый URL
   - Иначе формирует URL с базовым путем

2. **Объект:**
   - Проверяет различные поля: `url`, `url_full`, `src`, `image`, `large`, `medium`, `small`, `value`, `original`, `plan`, `thumbnail`, `full`
   - Если есть `path` и `file_name` - формирует URL: `https://selcdn.trendagent.ru/images/${path}/m_${fileName}`

3. **Массив:**
   - Берет первый элемент и обрабатывает рекурсивно

## Формат URL изображений

- **Миниатюра:** `https://selcdn.trendagent.ru/images/${path}/m_${fileName}`
- **Полный размер:** `https://selcdn.trendagent.ru/images/${path}/${fileName}`
