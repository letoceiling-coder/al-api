# 🚀 Быстрый старт: Развертывание TrendAgent

## ✅ Команда создана

Команда `php artisan deploy:trendagent` готова к использованию!

---

## 📋 Использование

### На локальной машине (Windows)

```bash
# Отправить изменения в Git
php artisan deploy:trendagent
```

### На сервере (Linux)

```bash
# Полное развертывание
php artisan deploy:trendagent
```

Команда автоматически:
1. ✅ Обновит проект из Git
2. ✅ Установит зависимости Composer
3. ✅ Установит зависимости NPM
4. ✅ Соберет проект (`npm run build`)
5. ✅ Выполнит миграции
6. ✅ Очистит и оптимизирует кеш

---

## 🔧 Решение проблемы на сервере

Если на сервере ошибка `Cannot find package '@vitejs/plugin-react'`:

```bash
# На сервере выполните:
cd /var/www/AL
php artisan deploy:trendagent
```

Команда автоматически установит все зависимости NPM и соберет проект.
