📖 API Документация

Base URL

https://api.siteaccess.ru/api

Аутентификация

Все endpoints (кроме /test) требуют Sanctum Bearer token:

Authorization: Bearer {your_sanctum_token}

Основные Endpoints

1. Test Endpoint

GET /api/test

Проверка работы API

curl https://api.siteaccess.ru/api/test

2. Process AI Request (Главный endpoint)

POST /api/ai/process

Отправка запроса к AI провайдеру (Gemini или OpenAI)

Пример запроса:

curl -X POST \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Content-Type: application/json' \
  -d '{
    "provider": "gemini",
    "model": "gemini-1.5-pro",
    "prompt": "Explain quantum computing"
  }' \
  https://api.siteaccess.ru/api/ai/process

Формат запроса:

{
  "provider": "gemini|openai",    // Обязательно
  "model": "gemini-1.5-pro",       // Обязательно
  "prompt": "Your prompt",         // Обязательно
  "user_api_key": "optional",      // Опционально
  "parameters": {                  // Опционально
    "temperature": 0.7,
    "max_tokens": 1000
  },
  "files": [...]                   // Опционально (для vision)
}

Формат ответа:

{
  "success": true,
  "request_id": "uuid",
  "data": {
    "provider": "gemini",
    "model": "gemini-1.5-pro",
    "response": {
      "text": "Generated response...",
      "finish_reason": "stop"
    }
  },
  "usage": {
    "prompt_tokens": 150,
    "completion_tokens": 300,
    "total_tokens": 450,
    "estimated_cost": 0.000675
  },
  "limits": {
    "daily_requests_remaining": 55
  }
}

3. Управление API ключами

Метод Endpoint Описание
GET /api/user/keys Список всех ключей
POST /api/user/keys Добавить новый ключ
GET /api/user/keys/{id} Детали ключа
PUT /api/user/keys/{id} Обновить ключ
DELETE /api/user/keys/{id} Удалить ключ

4. Аналитика

Endpoint Описание
/api/analytics/summary Общая статистика
/api/analytics/history История запросов
/api/analytics/costs Расходы за 30 дней
/api/analytics/limits Текущие лимиты

🏗️ Архитектура

Основные компоненты

  • API Gateway - Единая точка входа для всех AI запросов
  • Key Management - Управление API ключами (internal/user)
  • Analytics - Отслеживание использования и стоимости
  • Rate Limiting - Ограничение запросов
  • Request Logging - Логирование всех запросов

База данных

  • user_ai_keys - API ключи пользователей
  • ai_request_logs - Логи запросов
  • user_usage_stats - Статистика по дням
  • user_limits - Лимиты пользователей
