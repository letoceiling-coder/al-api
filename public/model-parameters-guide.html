Model Parameters Guide

Complete reference for all AI model parameters v1

📝 Note: All parameters are optional. Default values will be used if not specified.

Common Parameters

These parameters are supported by both Gemini and OpenAI models:

Parameter Type Range Default Description
temperature float 0.0 - 2.0 1.0 (Gemini)
1.0 (OpenAI)		 Controls randomness. Lower = more deterministic, Higher = more creative
top_p float 0.0 - 1.0 0.95 (Gemini)
1.0 (OpenAI)		 Nucleus sampling. Considers tokens with cumulative probability up to top_p
max_tokens integer 1 - model max 1024 Maximum number of tokens to generate

Example Usage (Common Parameters)

{
  "provider": "gemini",
  "model": "gemini-1.5-pro",
  "prompt": "Write a creative story",
  "parameters": {
    "temperature": 1.2,
    "top_p": 0.9,
    "max_tokens": 2048
  }
}

Gemini Specific Parameters

Parameter Type Range/Values Default Description
top_k integer 1 - 100 40 Top-K sampling. Considers only the top K most likely tokens
max_output_tokens integer 1 - 8192 2048 Maximum tokens in response (Gemini-specific)
stop_sequences array Max 5 sequences [] Array of strings that will stop generation
candidate_count integer 1 - 8 1 Number of response variations to generate
safety_settings array See below Default safety Content safety filter settings

Safety Settings Structure

{
  "safety_settings": [
    {
      "category": "HARM_CATEGORY_HARASSMENT",
      "threshold": "BLOCK_MEDIUM_AND_ABOVE"
    },
    {
      "category": "HARM_CATEGORY_HATE_SPEECH",
      "threshold": "BLOCK_ONLY_HIGH"
    },
    {
      "category": "HARM_CATEGORY_SEXUALLY_EXPLICIT",
      "threshold": "BLOCK_MEDIUM_AND_ABOVE"
    },
    {
      "category": "HARM_CATEGORY_DANGEROUS_CONTENT",
      "threshold": "BLOCK_MEDIUM_AND_ABOVE"
    }
  ]
}

Safety Categories

  • HARM_CATEGORY_HARASSMENT
  • HARM_CATEGORY_HATE_SPEECH
  • HARM_CATEGORY_SEXUALLY_EXPLICIT
  • HARM_CATEGORY_DANGEROUS_CONTENT

Safety Thresholds

  • BLOCK_NONE - No blocking
  • BLOCK_ONLY_HIGH - Block only high probability harmful content
  • BLOCK_MEDIUM_AND_ABOVE - Block medium and high (default)
  • BLOCK_LOW_AND_ABOVE - Block low, medium and high

Gemini Example Request

{
  "provider": "gemini",
  "model": "gemini-1.5-pro",
  "prompt": "Explain quantum computing in simple terms",
  "parameters": {
    "temperature": 0.7,
    "top_p": 0.95,
    "top_k": 40,
    "max_output_tokens": 1024,
    "stop_sequences": ["END", "STOP"],
    "candidate_count": 1,
    "safety_settings": [
      {
        "category": "HARM_CATEGORY_HARASSMENT",
        "threshold": "BLOCK_MEDIUM_AND_ABOVE"
      }
    ]
  }
}

OpenAI Specific Parameters

Parameter Type Range/Values Default Description
presence_penalty float -2.0 to 2.0 0 Penalizes new tokens based on presence in text so far. Positive = encourage new topics
frequency_penalty float -2.0 to 2.0 0 Penalizes tokens based on frequency. Positive = reduce repetition
n integer 1 - 10 1 Number of chat completion choices to generate
stop array Max 4 sequences null Up to 4 sequences where API will stop generating
logit_bias object Token ID: -100 to 100 {} Modify likelihood of specified tokens appearing
user string Max 255 chars null Unique identifier for end-user (for monitoring/abuse)
seed integer Any integer null Deterministic sampling (GPT-4 Turbo+)
response_format object See below null Force output format (GPT-4 Turbo, GPT-3.5 Turbo)

Response Format (JSON Mode)

{
  "response_format": {
    "type": "json_object"
  }
}
⚠️ Important: When using JSON mode, you MUST include the word "JSON" in your prompt. Example: "Return the response in JSON format."

Logit Bias Example

Increase likelihood of token 1234 by 50, decrease 5678 by 50:

{
  "logit_bias": {
    "1234": 50,
    "5678": -50
  }
}

OpenAI Example Request

{
  "provider": "openai",
  "model": "gpt-4-turbo-preview",
  "prompt": "Write a function to calculate fibonacci numbers. Return as JSON.",
  "parameters": {
    "temperature": 0.5,
    "top_p": 1.0,
    "max_tokens": 1024,
    "presence_penalty": 0.3,
    "frequency_penalty": 0.3,
    "n": 1,
    "stop": ["END", "STOP"],
    "user": "user-123",
    "seed": 42,
    "response_format": {
      "type": "json_object"
    }
  }
}

Parameter Combinations & Best Practices

1. Creative Writing (High Creativity)

{
  "parameters": {
    "temperature": 1.5,
    "top_p": 0.9,
    "top_k": 50,          // Gemini
    "presence_penalty": 0.6  // OpenAI
  }
}

2. Factual/Technical (Low Creativity)

{
  "parameters": {
    "temperature": 0.3,
    "top_p": 0.9,
    "top_k": 20,          // Gemini
    "frequency_penalty": 0.0  // OpenAI
  }
}

3. Code Generation (Deterministic)

{
  "parameters": {
    "temperature": 0.2,
    "top_p": 0.95,
    "seed": 42,           // OpenAI
    "max_tokens": 2048
  }
}

4. JSON Output (Structured Data)

{
  "prompt": "Return user data as JSON with fields: name, age, email",
  "parameters": {
    "temperature": 0.5,
    "response_format": {  // OpenAI only
      "type": "json_object"
    }
  }
}

Tips & Recommendations

💡 Best Practices:

1. Temperature: Start with 0.7, adjust based on use case
• 0.0-0.3: Factual, deterministic
• 0.4-0.9: Balanced
• 1.0-2.0: Creative, experimental

2. top_p vs top_k:
• Use top_p for most cases (more stable)
• Use top_k when you need strict control
• Don't use both at max values simultaneously

3. Penalties (OpenAI):
• presence_penalty: Encourage topic diversity
• frequency_penalty: Reduce repetition
• Start with 0.0, increase gradually

4. max_tokens:
• Set based on expected response length
• Higher values = more cost
• Monitor usage in analytics

5. Safety Settings (Gemini):
• Default is usually appropriate
• Adjust only if needed for your use case
• More restrictive = fewer blocked responses
