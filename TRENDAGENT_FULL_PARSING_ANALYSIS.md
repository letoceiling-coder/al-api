```
1. GET /blocks/search?room=[50]  → Список комплексов с паркингами
```

- Тип (открытый/закрытый)
- Этаж/уровень
- Секция/корпус

### ЭТАП 3: Обновление ParseCommand (3-4 часа)

#### 3.1. Изменить логику парсинга

**Текущая логика (НЕПРАВИЛЬНАЯ)**:
```
parseType('parkings') → API возвращает комплексы → сохраняем 344 комплекса
```

**Правильная логика (НУЖНАЯ)**:
```
1. parseType('parkings') → API возвращает комплексы с паркингами
2. Для каждого комплекса:
   - getBlockParkings($blockId) → получаем все машиноместа
   - сохраняем каждое машиноместо отдельно
3. Итого: 3,644 машиномест
```

#### 3.2. Структура методов парсинга

```php
private function parseParkingsType(): void
{
    // 1. Получить комплексы с паркингами (room=50)
    $complexes = getComplexesWithParkings();
    
    // 2. Для каждого комплекса
    foreach ($complexes as $complex) {
        $parkings = $this->apiClient->getBlockParkings($complex['_id']);
        
        // 3. Сохранить все машиноместа
        $this->saveParkingData($complex['_id'], $parkings);
    }
}

private function parseHousesType(): void
{
    // 1. Получить комплексы с домами (room=30,40)
    $complexes = getComplexesWithHouses();
    
    // 2. Для каждого комплекса
    foreach ($complexes as $complex) {
        // Получить дома
        $houses = $this->apiClient->getBlockHouses($complex['_id']);
        
        // Получить планировки
        if ($this->parseDetails) {
            $plans = $this->apiClient->getBlockPlans($complex['_id']);
        }
        
        // 3. Сохранить
        $this->saveHousesData($complex['_id'], $houses, $plans);
    }
}

private function parsePlotsType(): void
{
    // 1. Получить поселки
    $villages = $this->apiClient->getVillagesSearch();
    
    // 2. Для каждого поселка
    foreach ($villages as $village) {
        // Получить участки
        $plots = $this->apiClient->getVillagePlots($village['_id']);
        
        // 3. Сохранить
        $this->savePlotsData($village['_id'], $plots);
    }
}

private function parseCommercialType(): void
{
    // 1. Получить комплексы с коммерцией (room=110,120,130)
    $complexes = getComplexesWithCommercial();
    
    // 2. Для каждого комплекса
    foreach ($complexes as $complex) {
        // Получить помещения
        $commercial = $this->apiClient->getBlockCommercial($complex['_id']);
        
        // Получить планировки
        if ($this->parseDetails) {
            $plans = $this->apiClient->getBlockPlans($complex['_id']);
        }
        
        // 3. Сохранить
        $this->saveCommercialData($complex['_id'], $commercial, $plans);
    }
}
```
