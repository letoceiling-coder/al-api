# 🎯 Критически важное обновление плана парсера

**Дата:** 2026-02-07  
**Обновление:** Добавлен полный парсинг ВСЕХ объектов с детализацией

---

## ⚠️ КРИТИЧЕСКИЕ изменения в плане парсинга

### Проблема, которую решаем:

Исходный план предполагал парсинг только **списков** объектов. Но для полноценной работы системы нужно сохранять **КАЖДЫЙ** объект со всеми деталями:

- ✅ **Все квартиры комплекса** (не только список, но и детали каждой)
- ✅ **Все места парковки** (каждое место отдельно)
- ✅ **Все участки в поселке** (каждый участок отдельно)
- ✅ **Все фотографии** (планы, галереи, виды)
- ✅ **Все метаданные** для фильтров и сортировки

---

## 🔄 Что добавлено в план

### 1. Полный парсинг квартир комплекса

**Было:**
```
POST /api/trendagent/v1/apartments
→ Получить список квартир (100 шт)
```

**Стало:**
```
1. POST /api/trendagent/v1/apartments/{id}
   → Детали комплекса

2. POST /api/trendagent/v1/apartments/{id}/checkerboard/apartments
   → ВСЕ квартиры комплекса (может быть 150+)

3. Для КАЖДОЙ квартиры:
   POST /api/trendagent/v1/apartments/{complexId}/flat/{apartmentId}
   → Детальная информация квартиры

4. Скачать ВСЕ изображения:
   - План каждой квартиры
   - Виды из окон
   - Галерея комплекса
```

### 2. Полный парсинг мест парковки

**Было:**
```
POST /api/trendagent/v1/parkings/{id}
→ Информация о паркинге
```

**Стало:**
```
1. POST /api/trendagent/v1/parkings/{id}
   → Информация о паркинге

2. POST /api/trendagent/v1/parkings/{id}/places
   → ВСЕ места парковки

3. Сохранить каждое место с:
   - Номер, уровень, статус, цена
   - План парковки
   - Фотографии
```

### 3. Полный парсинг участков в поселке

**Было:**
```
POST /api/trendagent/v1/plots/{id}
→ Информация о поселке
```

**Стало:**
```
1. POST /api/trendagent/v1/plots/{id}
   → Информация о поселке

2. Для КАЖДОГО участка:
   POST /api/trendagent/v1/plots/{id}/plot/{plotId}
   → Детали участка

3. Скачать:
   - Генплан поселка
   - Фото каждого участка
```

## 📊 Обновлённая последовательность парсинга

### Для комплексов с квартирами:

1. Получить список комплексов
2. Для каждого комплекса:
   - Получить детали комплекса
   - Получить **ВСЕ** квартиры через шахматку
   - Для **КАЖДОЙ** квартиры:
     - Получить детали
     - Скачать план
     - Скачать виды из окон
   - Скачать фото комплекса
   - Создать файл с фильтрами и сортировкой

### Для паркингов:

1. Получить список паркингов
2. Для каждого паркинга:
   - Получить детали
   - Получить **ВСЕ** места
   - Скачать фото/планы
   - Создать файл с фильтрами

### Для участков:

1. Получить список поселков
2. Для каждого поселка:
   - Получить детали поселка
   - Получить **ВСЕ** участки
   - Для **КАЖДОГО** участка получить детали
   - Скачать генплан
   - Скачать фото участков
   - Создать файл с фильтрами

## 🎯 Зачем это нужно

### 1. Полнота данных
- Сохранение **всех** квартир позволяет работать с полным каталогом
- Не нужно делать повторные запросы к API для каждой квартиры

### 2. Фильтрация на фронтенде
- Все данные для фильтров уже есть в JSON
- Фильтрация происходит мгновенно без запросов к серверу

### 3. Сортировка на фронтенде
- Данные можно сортировать по любому полю
- Не нужны дополнительные запросы к API

### 4. Офлайн-работа
- Все данные и изображения хранятся локально
- Система может работать независимо от TrendAgent API

### 5. База данных
- Структура JSON идеально подходит для импорта в БД
- Все связи и фильтры уже подготовлены
