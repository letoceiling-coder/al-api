## ⚠️ Ограничения TrendAgent API

### Лимит пагинации
API имеет **жесткий лимит offset = 344** для всех типов объектов:
- При offset > 344 API возвращает пустой массив
- Это защитный механизм против массового скрейпинга
- Применяется ко всем endpoints кроме вложенных объектов (квартир в комплексах)

### Размер страницы
- Запрашивали: 100 объектов на страницу
- Получали реально: **~40 объектов** на запрос
- Это означает, что для получения 344 объектов требуется 9-10 запросов

## 🔧 Технические детали

### Формат данных
Каждый JSON файл содержит:
```json
{
  "metadata": {
    "region": "spb",
    "type": "complexes",
    "data_type": "list",
    "timestamp": "2026-02-07T19:24:44+00:00",
    "identifier": 0,
    "limit": 100000,
    "items_count": 40
  },
  "data": {
    "success": true,
    "data": [ /* массив объектов */ ],
    "total": 354
  }
}
```

### Параметры парсинга
```bash
php artisan trendagent:parse \
  --region=spb \
  --type=complexes \
  --limit=10000 \
  --details \
  --save-raw
```

- `--details` - для комплексов загружает все вложенные квартиры
- `--save-raw` - сохраняет полные ответы API
- `--download-images` - опционально скачивает изображения (по умолчанию только URL)
