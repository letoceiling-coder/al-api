## ⚠️ Опциональные компоненты (СРЕДНИЙ приоритет)

Эти компоненты **не реализованы**, но не критичны:

### 1. DetailAggregator

**Назначение:** Агрегация данных из множественных endpoints для сложных объектов (BLOCKS - 22 endpoints)

**Текущее состояние:**
- DetailService работает для всех типов объектов
- Для BLOCKS используется один запрос (getBlockUnified)
- Агрегация 22 endpoints не реализована

**Влияние:**
- ⚠️ Для BLOCKS не загружаются все связанные данные (преимущества, инфраструктура, банки, и т.д.)
- ✅ Основные данные загружаются
- ✅ Для других типов объектов работает полностью

**Рекомендация:** Можно добавить позже при необходимости полной агрегации для BLOCKS

### 2. EntityNormalizer

**Назначение:** Нормализация данных из API в типизированные Entity классы

**Текущее состояние:**
- Данные возвращаются как массивы
- Нет типизации свойств
- Нет Value Objects (Price, Area, Location)

**Влияние:**
- ⚠️ Нет строгой типизации
- ✅ Данные доступны и работают
- ✅ Можно использовать массивы

**Рекомендация:** Можно добавить позже для улучшения типизации

### 3. Entity классы

**Назначение:** Типизированные классы для каждого типа объекта

**Текущее состояние:**
- Нет ApartmentEntity, BlockEntity, и т.д.
- Данные возвращаются как массивы

**Влияние:**
- ⚠️ Нет строгой типизации свойств
