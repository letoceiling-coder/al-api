# Исправление ошибки "Cannot GET /apar" для детальной страницы квартиры

## Проблема

При запросе к `/api/trendagent/apartments/{id}/flat/{apartmentId}` возникает ошибка 500:
```
Cannot GET /apar...
```

Это указывает на то, что API TrendAgent возвращает HTML ошибку вместо JSON.

## Возможные причины

1. **Неправильный формат URL** - API может требовать другой формат эндпоинта
2. **Отсутствие квартиры** - Квартира с таким ID может не существовать
3. **Проблемы с авторизацией** - Токен может быть недействительным
4. **Неправильные параметры** - API может требовать дополнительные параметры

## Реализованные исправления

### 1. Добавлено кэширование
- Метод `getApartmentDetail()` теперь кэшируется на 60 минут
- Это снижает нагрузку на API и ускоряет ответы

### 2. Улучшена обработка ошибок
- Добавлена обработка HTML ошибок
- Извлечение текста ошибки из HTML ответа
- Более подробное логирование

### 3. Улучшено логирование
- Логируется полный URL запроса
- Логируется статус код и тело ответа
- Логируется информация об ошибках

## Что нужно проверить на сервере

### 1. Проверить логи Laravel
```bash
tail -f /var/www/AL/storage/logs/laravel.log | grep "apartment detail"
```

### 2. Проверить, что URL формируется правильно
В логах должно быть:
```
Запрос к API apartment detail
apartment_id: 63c6434a9a85d5aa3ef682b2
block_id: 63c50acc9a85d53360f63a76
url: https://api.trendagent.ru/v4_29/apartments/block/63c50acc9a85d53360f63a76/apartment/63c6434a9a85d5aa3ef682b2/
```

### 3. Проверить ответ API
Если API возвращает HTML ошибку, нужно:
- Проверить, что токен авторизации действителен
- Проверить, что квартира существует
- Проверить, что формат URL правильный

## Возможные решения

### Вариант 1: Проверить формат URL
API TrendAgent может требовать другой формат. Проверьте документацию API или попробуйте:
```
https://api.trendagent.ru/v4_29/apartments/{apartmentId}/
```
вместо
```
https://api.trendagent.ru/v4_29/apartments/block/{blockId}/apartment/{apartmentId}/
```

### Вариант 2: Проверить параметры запроса
API может требовать дополнительные параметры, например:
- `building_id`
- `section_id`
- Другие параметры фильтрации

### Вариант 3: Проверить авторизацию
Убедитесь, что токен авторизации действителен и передается правильно.
