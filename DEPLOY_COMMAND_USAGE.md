# 📦 Команда развертывания TrendAgent

**Команда:** `php artisan deploy:trendagent`

## 📋 Описание

Команда автоматизирует процесс развертывания проекта TrendAgent из директории `projects/trendagent/`. 

Команда автоматически определяет, запущена ли она на локальной машине или на сервере, и выполняет соответствующие действия.

---

## 🖥️ Локальное использование

На локальной машине команда:
1. ✅ Отправляет изменения в Git (git add, commit, push)

**Пример:**
```bash
php artisan deploy:trendagent
```

**Пропустить отправку в Git:**
```bash
php artisan deploy:trendagent --skip-git
```

---

## 🖥️ Использование на сервере

На сервере команда выполняет полный цикл развертывания:

1. ✅ **Обновление из Git** (`git pull`)
2. ✅ **Установка зависимостей Composer** (`composer install --no-dev --optimize-autoloader`)
3. ✅ **Установка зависимостей NPM** (`npm install`)
4. ✅ **Сборка проекта** (`npm run build`)
5. ✅ **Выполнение миграций** (`php artisan migrate --force`)
6. ✅ **Очистка и оптимизация кеша** (`cache:clear`, `config:clear`, `route:clear`, `view:clear`, `config:cache`, `route:cache`)

**Пример:**
```bash
php artisan deploy:trendagent
```

**Пропустить отдельные шаги:**
```bash
# Пропустить сборку
php artisan deploy:trendagent --skip-build

# Пропустить миграции
php artisan deploy:trendagent --skip-migrations

# Пропустить очистку кеша
php artisan deploy:trendagent --skip-cache

# Пропустить несколько шагов
php artisan deploy:trendagent --skip-build --skip-migrations
```

Для просмотра детального вывода команд используйте флаг `--verbose`:


---

## ⚙️ Определение сервера

Команда определяет сервер по следующим признакам:
- Hostname содержит `titdsftsmw` или `server`
- Существует путь `/var/www/AL/projects/trendagent`

Если ни одно условие не выполнено, команда работает в режиме локальной машины.

## 🐛 Устранение неполадок

### Ошибка: "Cannot find package '@vitejs/plugin-react'"
**Решение:** На сервере выполните:
```bash
cd /var/www/AL/projects/trendagent
npm install
php artisan deploy:trendagent
```

### Ошибка: "git pull failed"
**Решение:** Проверьте права доступа и наличие репозитория:
```bash
cd /var/www/AL
git status
```

### Ошибка: "composer install failed"
**Решение:** Проверьте наличие Composer и права:
```bash
composer --version
```

## 📝 Примечания

- Команда автоматически определяет окружение (локальное/серверное)

- Для детального вывода используйте `-v` или `--verbose`
