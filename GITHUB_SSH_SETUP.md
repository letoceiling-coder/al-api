1. Откройте GitHub в браузере: https://github.com
2. Войдите в свой аккаунт `letoceiling-coder`
3. Перейдите в **Settings** (нажмите на аватар в правом верхнем углу → Settings)
4. В левом меню выберите **SSH and GPG keys**
5. Нажмите кнопку **New SSH key** (зеленая кнопка справа)
6. Заполните форму:
   - **Title**: `AL API Server (89.169.39.244)` или любое понятное название

   - **Key**: Вставьте скопированный публичный ключ
7. Нажмите **Add SSH key**
8. Подтвердите действие, введя пароль GitHub (если потребуется)

## 🔒 Безопасность

- **Никогда не делитесь приватным ключом** (`~/.ssh/id_ed25519`)
- Публичный ключ (`~/.ssh/id_ed25519.pub`) безопасно добавлять в GitHub
- Если ключ скомпрометирован, удалите его из GitHub и создайте новый

## ⚠️ Если что-то пошло не так

Если при проверке подключения возникает ошибка:

1. Проверьте, что ключ правильно скопирован (без лишних пробелов)
2. Убедитесь, что вы добавили ключ в правильный аккаунт GitHub
3. Проверьте права доступа:
   ```bash

   chmod 644 ~/.ssh/id_ed25519.pub
   ```
