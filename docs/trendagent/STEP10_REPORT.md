# ШАГ 10 — Hardening Import

**Дата:** 2026-02-15

## Опции ImportDataCommand

| Опция | По умолчанию | Описание |
|-------|--------------|----------|
| --batch | 500 | Размер пачки |
| --fail-fast | 0 | 1 = остановиться при первой ошибке пачки |
| --timeout | 30 | Таймаут HTTP для скачивания (сек) |
| --retries | 2 | Повторные попытки скачивания |
| --max-image-size-mb | 25 | Макс. размер изображения (MB) |
| --download-images | 0 | 1 = скачивать изображения |
| --images-disk | public | Диск для изображений |
| --images-dir | trendagent | Подпапка |
| --dry-run | — | Без записей в БД и без скачивания |

## Batch + транзакции

- Записи обрабатываются пачками по `--batch`
- Каждая пачка в `DB::transaction()`
- При fail-fast и ошибке — rollback и остановка

## Dry-run

- Не создаёт/не обновляет записи в БД
- Не скачивает файлы
- Только подсчёт статистики

## TrendAgentImageStoreService

- Поддержка timeout, maxSizeMb, retries в конструкторе
- Retry-логика: до retries+1 попыток с паузой 200ms
