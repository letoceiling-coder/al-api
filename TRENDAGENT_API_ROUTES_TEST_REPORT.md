## Анализ структуры данных

### Общие поля в ответах

Все успешные ответы содержат:

1. **`success: true`** - индикатор успешного выполнения запроса
2. **`data`** - основные данные ответа
3. **`pagination`** (для списков) - информация о пагинации:
   - `count` - запрошенное количество
   - `offset` - смещение
   - `page` - номер страницы
   - `has_more` - есть ли еще данные
   - `returned_count` - фактически возвращено

### Структура объекта в списке

Каждый объект в списке содержит:

- **Идентификаторы:**
  - `_id` - MongoDB ObjectId
  - `guid` - строковый идентификатор (slug)

- **Основная информация:**
  - `name` - название объекта
  - `address` - адрес
  - `city` - информация о городе

- **Цены:**
  - `min_price` - минимальная цена
  - `max_price` - максимальная цена

- **Характеристики:**
  - `apart_count` - количество квартир (для квартир)
  - `places_count` - количество мест (для паркингов)
  - `status` - статус объекта
  - `deadline` - срок сдачи

- **Медиа:**
  - `image` - изображение объекта:
    - `url` - миниатюра
    - `url_full` - полный размер

- **Геолокация:**
  - `latitude` - широта
  - `longitude` - долгота

### Структура детальной информации

Детальная информация объекта содержит секции:

1. **`unified`** - общая информация:
   - Основные характеристики
   - Описание
   - Изображения (renderer)

2. **`apartments`** - квартиры:
   - Список всех квартир
   - Фильтрация по параметрам
   - Статистика (total, on_request_count, booked_count)

3. **`buildings`** - здания:
   - Информация о зданиях в комплексе
   - Характеристики зданий

4. **`plans`** - планировки:
   - Изображения планировок
   - Метаданные планировок

5. **`progress`** - ход строительства:
   - Фотографии по годам
   - Информация о прогрессе

6. **`finishings`** - отделка:
   - Варианты отделки
   - Изображения отделки

7. **`advantages`** - преимущества:
   - Список преимуществ
   - Изображения преимуществ

8. **`nearby_places`** - места рядом:
   - Список мест
   - Изображения мест
   - Расстояния

9. **`min_price`** - минимальная цена:
   - Текущая минимальная цена
   - История изменения цен

10. **`videos`** - видео:
    - Ссылки на видео
    - Метаданные видео

11. **`files`** - файлы:
    - Документы
    - Брошюры
    - Презентации
